V11.11 本機測試版

一、本版範圍
1. 等待時間顯示格式、內部秒數與排序方式維持 V11.10。
2. D+1／D+3 工作日色碼規則維持不變，截止時間為工作日 17:00。
3. 移除「案件篩選」與「等待時間」兩個輔助標題。
4. 四個篩選選項與三組等待色碼直接併成單層橫列，列高收至 34px。
5. 等待時間圖例、已結案樣式、結案排序與 SOP 明細維持 V11.10。

二、色碼邊界說明
1. 等待時間文字顯示實際經過時間。
2. 黃色警示於 D+1 工作日 17:00 起生效。
3. 紅色逾期於 D+3 工作日 17:00 起生效。
4. 例如 8/5 13:55 建立，8/6 16:38 顯示 1天 02時但仍為正常；8/6 17:00 起轉為警示。

三、本機預覽
1. 將完整壓縮檔解壓縮到獨立資料夾。
2. 在 VS Code 開啟該資料夾。
3. 終端機執行：py -m pip install -r requirements.txt
4. 終端機執行：py -m streamlit run app.py
5. 開啟 http://localhost:8501
6. 預覽結束後按 Ctrl+C。
