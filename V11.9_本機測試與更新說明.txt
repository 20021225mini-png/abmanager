V11.9 本機測試版

一、本版範圍
1. 未滿 24 小時：HH時 MM分。
2. 滿 24 小時：X天 HH時。
3. 內部仍保留 elapsed_seconds，等待時間計算、排序與資料來源不變。
4. D+1／D+3 工作日色碼規則不變。
5. 第二列左側為案件階段，右側以膠囊色框顯示等待時間的逾期、警示與正常狀態。
6. 已結案等待時間不顯示底色，改為粗體文字。
7. 圖例色框與下方案件等待時間使用相同底色與文字色，狀態文字採一般字重。

二、本機預覽
1. 將完整壓縮檔解壓縮到獨立資料夾。
2. 在 VS Code 開啟該資料夾。
3. 終端機執行：py -m pip install -r requirements.txt
4. 終端機執行：py -m streamlit run app.py
5. 開啟 http://localhost:8501
6. 預覽結束後按 Ctrl+C。

三、驗收項目
[ ] 23小時59分顯示 23時 59分。
[ ] 24小時整顯示 1天 00時。
[ ] 51小時30分顯示 2天 03時。
[ ] 全部／待處理／處理中／已結案位於第二列左側。
[ ] 等待時間灰／黃／紅說明位於第二列右側，文字大小與案件篩選一致。
[ ] 紅色色框顯示「逾期」，右側文字為「達 3 個工作日」。
[ ] 黃色色框顯示「警示」，右側文字為「達 1 個工作日」。
[ ] 灰色色框顯示「正常」，右側文字為「未滿 1 個工作日」。
[ ] 圖例狀態與門檻文字皆為一般字重。
[ ] 已結案等待時間只有粗體時間，不顯示灰色底框。
[ ] SOP 左 60%／案件摘要右 40% 維持不變。
[ ] 案件判定與寫回仍不顯示。
