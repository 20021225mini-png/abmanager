V11.3 相容修正版

本版只修正 app.py 與 ui/dashboard.py 版本不一致時的啟動錯誤。
原案件列表的欄位、配色、節點與版面不變。

建議更新方式：
1. 在 GitHub 確認目前位於 Streamlit 實際部署的分支。
2. 將本壓縮檔「內部內容」上傳到 Repository 根目錄，不要多包一層資料夾。
3. Commit 畫面必須看得到 app.py 與 VERSION.txt。
4. 若要啟用完整 V11 判定功能，Commit 畫面也必須看得到 ui/dashboard.py、ui/judgement.py、services/judgement_service.py 與 data/case_writer.py。
5. Commit 後開啟 GitHub 根目錄的 VERSION.txt，內容應為 V11.3-COMPAT。
6. 到 Streamlit Manage app 確認 Branch 與 GitHub 相同，再按 Reboot app。

快速確認：
- GitHub 根目錄 app.py 應可搜尋 _render_dashboard_compatibly。
- GitHub 根目錄 ui/dashboard.py 的 render_dashboard 應包含 judgement_service 與 case_writer。
- 即使第二項仍是舊版，本版 app.py 也會先以原畫面正常啟動，不再因 unexpected keyword argument 停止。
